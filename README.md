# PINN для задач изгиба пластины

Проект посвящён применению нейронных сетей с физическими ограничениями (Physics-Informed Neural Networks, PINN) для моделирования изгиба пластин.

Модель обучается приближать решение уравнения механики, учитывая как само уравнение, так и граничные условия. На первом этапе рассматриваются простые задачи с известными решениями, чтобы проверить корректность реализации и оценить точность метода.

Далее планируется расширить подход на разные параметры материала и нагрузки, а также на более сложные нелинейные модели взаимодействия пластины с упругим основанием.

Проект реализован на Python с использованием PyTorch. Результаты PINN сравниваются с эталонными решениями с помощью численных метрик и визуализации прогиба.
